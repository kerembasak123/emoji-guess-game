## 📌 About The Project

**Emoji Guess Game** is an engaging puzzle application designed to test players' creativity and visual thinking. By combining various emojis, the app presents clever riddles ranging from popular movies and songs to everyday expressions.

## ✨ Key Features

* 🧠 **Diverse Categories:** Puzzles covering movies, pop culture, idioms, and common phrases.
* 💡 **Hint System:** Useful clues to assist players when stuck on challenging levels.
* 🏆 **Score & Progression:** Track your score and unlock new levels as you progress.
* 🎨 **Clean & Modern UI:** Intuitive interface designed for a seamless user experience.

## 🛠️ Tech Stack

* **Framework:** Flutter (Cross-platform iOS & Android)
* **Language:** Dart
